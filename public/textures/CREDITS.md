# Textures

All textures are from [Poly Haven](https://polyhaven.com/textures), licence **CC0 1.0** (public domain, https://creativecommons.org/publicdomain/zero/1.0/).
They were downloaded as 1K JPG, then resized and re-encoded as WebP (albedo 1024 px, normal map 512 px, OpenGL convention).
Use them through `src/tv/render/textures.ts` (see `docs/art-direction.md`).
